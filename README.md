# Midterm_Visualization
ช่วยสร้างหน้าเว็บไซต์ Data Visualization Technology ด้วย HTML, CSS และ D3.js
ฉันเป็นนักศึกษาที่ต้องทำงานเรื่องการแสดงผลข้อมูล โดยอาจารย์กำหนดให้สร้าง Dashboard ที่มีกราฟอย่างน้อย 3 ภาพ และต้องมีกราฟอย่างน้อย 2 ประเภท
อยากให้หน้าเว็บออกมาดูน่ารัก สวย อ่านง่าย ไม่ดูเป็นทางการหรือแก่เกินไป ใช้โทนสีพาสเทล และใช้ฟอนต์ที่ดูน่ารักแต่ยังอ่านภาษาไทยง่าย
หน้าแรกให้แสดง "ส่วนที่ 2: การปฏิบัติจริง" และให้กราฟอยู่หน้าแรกเลย
ส่วนที่ 1 ให้แยกเป็นอีกหน้าหนึ่ง และใช้สำหรับตอบคำถามเกี่ยวกับ Data Visualization
ด้านบนของเว็บไซต์ให้มีแบนเนอร์เขียนว่า
Data Visualization Technology
ไม่ต้องใส่ข้อความเกี่ยวกับคะแนนหรือบอกว่าเป็นงานกี่คะแนน
อยากให้มีเมนูสำหรับกดสลับระหว่าง
- ส่วนที่ 2
- ส่วนที่ 1
ส่วนที่ 1 ให้ใช้ฟอนต์และรูปแบบเดียวกับส่วนที่ 2 ขนาดตัวหนังสือต้องอ่านง่าย ไม่เล็กเกินไป
สำหรับส่วนที่ 2 ฉันมีชุดข้อมูล 2 ชุดดังนี้
ชุดข้อมูลที่ 1: Customer Satisfaction
[
  { "rating": "1 Star", "count": 50 },
  { "rating": "2 Stars", "count": 30 },
  { "rating": "3 Stars", "count": 70 },
  { "rating": "4 Stars", "count": 100 },
  { "rating": "5 Stars", "count": 200 }
]
อยากให้ชุดข้อมูลนี้แสดงเป็น Donut Chart
และสามารถกดเลือก 1 Star, 2 Stars, 3 Stars, 4 Stars, 5 Stars หรือทั้งหมดได้
เมื่อกดเลือกข้อมูล ต้องแสดงเฉพาะข้อมูลที่เลือก และกราฟต้องเปลี่ยนตามข้อมูลที่เลือก ไม่ใช่กดแล้วกราฟหายหรือแสดงผิด
ให้มีตัวเลขสรุป เช่น
- จำนวนผู้ตอบ
- คะแนนเฉลี่ย
- ระดับที่เลือก
เพิ่ม Tooltip ตอนเอาเมาส์ไปวางบนกราฟ และมี Animation ตอนกราฟแสดงผล
ชุดข้อมูลที่ 2: Monthly Revenue
[
    {
        "month": "มกราคม",
        "revenue": 120000,
        "expenses": 70000,
        "profit": 50000
    },
    {
        "month": "กุมภาพันธ์",
        "revenue": 135000,
        "expenses": 75000,
        "profit": 60000
    },
    {
        "month": "มีนาคม",
        "revenue": 150000,
        "expenses": 80000,
        "profit": 70000
    },
    {
        "month": "เมษายน",
        "revenue": 142000,
        "expenses": 78000,
        "profit": 64000
    },
    {
        "month": "พฤษภาคม",
        "revenue": 165000,
        "expenses": 85000,
        "profit": 80000
    },
    {
        "month": "มิถุนายน",
        "revenue": 180000,
        "expenses": 90000,
        "profit": 90000
    }
] 
อยากให้ชุดข้อมูลที่ 2 แสดงผลเป็นกราฟ Line Chart
โดยแกน X เป็นเดือน และแกน Y เป็นจำนวนเงิน
ให้แสดงข้อมูล 3 ค่าในกราฟ ได้แก่
- รายได้ (revenue)
- ค่าใช้จ่าย (expenses)
- กำไร (profit)
ต้องแสดงเส้นกราฟครบทั้ง 6 เดือน
มกราคม กุมภาพันธ์ มีนาคม เมษายน พฤษภาคม และมิถุนายน
อยากให้มีจุดข้อมูลทุกเดือน และมี Animation ตอนเส้นกราฟค่อย ๆ วาดขึ้นมา
เมื่อเอาเมาส์ไปวางบนจุด ให้มี Tooltip แสดง
- เดือน
- รายได้
- ค่าใช้จ่าย
- กำไร

ให้สามารถกด Filter เลือกเดือน
ทั้งหมด / มกราคม / กุมภาพันธ์ / มีนาคม / เมษายน / พฤษภาคม / มิถุนายน

เมื่อเลือกเดือนใด ให้เน้นข้อมูลของเดือนนั้น แต่ไม่ทำให้เส้นกราฟหายหรือกราฟพัง
และเมื่อกด "ทั้งหมด" ต้องกลับมาแสดงข้อมูลครบทั้ง 6 เดือนเหมือนเดิม
